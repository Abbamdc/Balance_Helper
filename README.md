# BalanceH - Shift Balance Calculator for Fuel Attendants

Live Demo: https://abbamdc.github.io/BalanceH/

## About
BalanceH is a simple, fast web app I built to solve a real problem I faced as a Fuel Attendant.

Manual calculation of daily sales, shortage/overage, and cash balance was slow and error-prone. This tool automates it.

## Features
- Input: Opening & Closing meter readings
- Input: Price per litre, Cash received, Expenses
- Auto-calculates: Total litres sold, Total sales amount, Expected balance
- Shows: Shortage / Overage instantly
- Clean, mobile-friendly design for use on phone at filling station

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Why I Built It
To help fuel attendants do "Daidaita lissafin shift" (Sales Reconciliation) in less than 2 minutes without errors.
